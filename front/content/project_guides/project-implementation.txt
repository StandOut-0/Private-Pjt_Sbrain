[프로젝트 구현 가이드]

아래 항목을 채워 보내면 프로젝트 요구사항을 구체화하는 데 도움이 됩니다. 모르는 항목은 비워두어도 됩니다.

1. 주요 상품 / 서비스:
   예: 반려동물 산책용품을 비교하고 구매하는 온라인 쇼핑몰
2. 주요 고객층:
   예: 20~40대 반려견 보호자, 모바일 구매 비중이 높은 고객
3. 만들고 싶은 서비스와 목표:
   예: 상품 탐색부터 주문까지 간단히 완료할 수 있는 반응형 쇼핑몰
4. 필요한 주요 기능:
   예: 회원가입, 상품 검색·필터, 상세 페이지, 장바구니, 주문 내역
5. 참고 서비스 / 디자인:
   예: 오늘의집의 카드형 목록, 밝은 배경, 녹색 포인트 컬러
6. 제약 조건과 우선순위:
   예: 우선 데모 화면을 완성하고 결제 연동은 다음 단계로 미룸

작성 예시:
반려견 산책용품 쇼핑몰을 만들고 싶습니다. 주요 고객은 20~40대 반려견 보호자입니다. 상품 검색, 카테고리 필터, 상품 상세, 장바구니를 우선 구현하고 싶습니다. 모바일에서 쓰기 편하고 밝은 아이보리와 초록색을 사용해주세요. 우선 결제 기능은 시연용으로 처리해주세요.
