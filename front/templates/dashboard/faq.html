FAQ · 이용 안내

처음 시작할 때 궁금한 점과 안전한 AI 사용 방법을 확인하세요.

AI 사용 안내

Second Brain은 안전한 서비스 이용을 위해 일부 요청을 제한할 수 있습니다.

  • 음란물성적으로 노골적인 콘텐츠 생성 요청
  • 폭력적 콘텐츠폭력 조장 및 타인에게 위해를 가하는 콘텐츠 요청
  • 불법 행위 지원범죄 실행을 돕는 구체적인 방법이나 도구 요청
  • 명백한 위험 행위자신이나 타인의 안전을 위협하는 행동을 돕는 요청

요청의 목적과 맥락을 명확히 설명해주세요. AI가 만든 내용에는 오류가 있을 수 있으므로 사용 전 확인하고, 비밀번호 등 민감한 정보는 입력하지 마세요.

자주 묻는 질문

처음에는 어디서 시작하면 되나요?

Dashboard에서 프로젝트를 확인하고 Projects에서 작업할 프로젝트를 선택하세요. 상단 나침반 버튼을 누르면 주요 화면을 둘러볼 수 있습니다.

사용자 가이드는 어디서 볼 수 있나요?

사이드바 하단의 사용자 가이드에서 PDF를 열거나 다운로드할 수 있습니다. 현재 제공되는 문서는 샘플 가이드입니다.

Google로 로그인하면 실제 계정이 연결되나요?

현재는 임시 계정을 사용하는 체험용 로그인입니다. 실제 Google 계정에 연결하거나 Google의 개인정보·파일에 접근하지 않습니다. 로그인 전 안내 화면에서 내용을 확인할 수 있습니다.

작업 중단이나 다시 만들기를 누르면 실제 작업이 바뀌나요?

현재 작업 중단 및 처음부터 다시 만들기는 UI 준비 단계입니다. 실제 Agent 실행 제어와 재실행은 연결되어 있지 않습니다.

생성된 결과물은 어디서 확인하나요?

프로젝트 상세 화면의 결과물 영역에서 파일 목록과 미리보기를 확인할 수 있습니다.
